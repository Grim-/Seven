# Decisions

- **You pick**: the agent offers options; each can roll a plain chance or a check against a DC. Before it rolls you can change who rolls, what they roll and the DC, or make it pass or fail.
- **Rolled**: name a die (d4 … d20) and the agent writes that many options; you roll and the die picks.
- **Opposed check**: one character against another. Change either side's stat, use a fixed DC, or decide the winner.
- **Stored decisions** keep a prompt (and optional fixed options) with tags. Use one from its screen, or mention it in chat as @decision:name.
