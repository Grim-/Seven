# Presentation

- present_card(title, body, footer): a card; body is markdown.
- present_code(language, code, title): code with line numbers and copy.
- present_document(title, body): a longer readable page; good with where "panel".
- where: inline, panel, stage or board:<name>. key: give the same key again to replace one (a running score, a status card).
- Each presentation shows once. If you were refused for showing it again, it's already on screen; carry on.
