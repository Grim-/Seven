# Python

- run_python(code, script): runs code, or a saved script by name, in its own work folder with a time limit. Use print() for results.
- python_save(name, code, description): keeps a script (encrypted) so you or the user can run it again; the user sees saved scripts in Data under Python, with their last runs.
- Files the script saves there (pictures, audio, video, PDFs) are shown to the user and in the Python tab of the side panel. Save charts with matplotlib's savefig.
- python_files lists or reads files in the work folder.
- Missing packages: say which and ask the user to install them; don't install them yourself unless asked.
