# Seven

> **An AI harness for home, not for developers.**

You run a model on your own machine. **Seven** provides everything around it: a library of your stuff, agents with tools and memory, and a screen that shows you things instead of just talking at you.

Most local-model apps are just a chat window paired with a model picker. Seven is the environment surrounding the model that makes a small local model genuinely useful day to day.

---

## Key Features

### 🛠️ Concrete Outputs, Not Vague Chat
The agent does the grunt work; you get something to act on. Agents handle the hard parts—tool selection, reasoning, and library read/write. What reaches you is concrete:

* **No vague "thinking..." states:** Everything on screen can be inspected, used, or changed.
* **Choices** appear as buttons.
* **Reasoning** is a box you can open and edit.
* **Characters** are formatted as sheets.
* **Plans** render as checklists.

### 🧩 Everything is a "Kind" ([Kinds](./documentation/kinds/overview.md)
Pages, files, chats, agents, themes, days, routines—everything shares a single unified concept.
* Finding, linking, showing, and exporting work identically across all item types.
* New features slot in naturally as new kinds.
* **Universal Linking:** Use `@kind:Name` anywhere. The syntax is identical for both you and your agents, everywhere in the app.

### 🛡️ Agents Act, You Decide
You can do anything an agent can—agents help, but they are never the only way in. You maintain full ownership over permissions, visibility, and active states at all times.

### 🔌 Extensible
Add-ons bring new tools, kinds, views, backgrounds, and presentations written in plain JavaScript and HTML.

### 🔒 Private by Default
* Runs 100% locally with all data remaining on your machine.
* Encrypted vault protects your data from being casually read by other applications.
* Privacy is built in as a given, not a selling point.

### 🎨 Atmospheric Design
Software should feel good to use. Atmospheric themes, customizable backgrounds, ambient music, and unique voices are core parts of the experience.
