Composer · mockup

A view of its own beside Data, Agents and Tools. One sheet of paper you write on and drop things onto. Send it to start a chat or into a chat, or save it as a page. A pad is a page, so it's one source of truth whichever agent narrates.

1 · The Composer view

Every kind is drawn by its own surface: pictures as pictures, cards as cards, characters with portraits. Drag anything from the side panel (or from Data, Files, the map, a hand) onto the paper; type between blocks. Right-click a block for Open, Roll again, Edit, Take out. Try dragging items across, and the "What the agent gets" switch.
