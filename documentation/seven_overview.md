# Seven


## What is a kind?

A 'Kind' can be anything, an internal markdown page, a .pdf document, a card, a character, a location, a place, a workout or excersize. Everything is reductible to a base 'Kind' which knows how to describe itself to an agent, in a structured coherent way.

Seven is an AI harness for home users. You run a model on your own machine, and Seven is everything around it: a library of your stuff, agents with tools and memory, and a screen that shows you things instead of just talking at you.

## Why it exists
- **A harness for home, not for developers.** Most local-model apps are a chat window and a model picker. Seven is the part around the model that makes a small local model useful day to day, it provides the agent a rich set of tools for a more pleasant user experience.
-
- No vague "thinking…": everything on screen is something you can look at, use, change or click.
-
- **Everything is a kind.** Pages, files, chats, agents, themes, days, routines: one concept, so finding, linking, showing and exporting work the same for all of them, and new things slot in as new kinds.

- **One way to link.** `@kind:Name`, the same for you and for agents, everywhere.

- **You can do anything an agent can.** Agents help; they're never the only way in. Agents act, you decide: permissions, what they see, and what's on are always yours.

- **Extensible.** Add-ons bring new tools, kinds, views, backgrounds and presentation styles.

- **Private by default, not a fortress.** Your flat file data is encrypted using your vault key, this helps with cases of hit and run collection of your files.

- **It should feel good to use.** Themes, backgrounds, music and voices are part of it. A little goes a long way.
