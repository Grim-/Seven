# Agents: more than a model and a system prompt

In most apps an "agent" is a model plus some instructions. In Seven an agent comes with a lot more built in, and all of it is yours to set up from the UI.

<!-- IMAGE: an agent's settings, or a chat with its avatar reacting -->

## Give it a character

Assign a character sheet to an agent in a chat and it plays that character. The sheet's **Mind** tab holds how the character talks: speaking style, cadence and an output filter. Swap the sheet and the same agent becomes someone else.

## Teach it how to think

A **reasoning style** is a reusable way of thinking things through before speaking: how a cautious detective weighs clues, how a hot-headed mercenary sizes up a fight. Make one once, then give it to a character or an agent.

Turn on **Always deliberate with reason before speaking** and the agent reasons first, every turn, in that style, before it writes anything.

## Give it a face

Agents have animated avatars: text-art faces, glitchy daemon cores, pictures and videos. They react to what's happening:

- **Moods**: the avatar looks happy, sad, angry or glitched as the agent's mood changes, and can have its own look for each.
- **Activity**: listening, thinking, using a tool, talking.
- **Reactions**: hits, heals and crits in play get their own flash and their own look.

You build and tweak them in the avatar studio, and agents can make them too.

<!-- GIF: the avatar studio, flicking through poses -->

## You decide what it sees and does

- Each agent sees only the parts of your library you let it see.
- Tools ask permission before they touch anything outside Seven.
- An agent's own memories stay private to it. Pages are shared, so anything every agent should know goes in a page.

## It all links together

An agent's instructions can [link](linking.md) pages, sheets, reasoning styles and repos, so its whole setup is made of pieces you can reuse elsewhere and change in one place.
