# Bundled Starter WorldPacks & Seven Cards

Drop `.sevenpack` bundles or `.png` Seven Cards exported from Seven into this folder (`resources/packs/`).

On startup (once the vault is unlocked), Seven automatically imports any pack in this folder that hasn't been installed yet (`defaultResolution: 'skip'`), bringing along the World's Places (`Looks`, `Exits`, `Inside`), Opening setup, Maps, Character Sheets, Trigger Actions, and Assets.
