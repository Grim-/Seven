# Seven: Agent Rules

These rules bind all work in the Seven codebase.

## User Data Boundary
- **Never inspect, read, list, grep, query or touch user data** outside the repository: `~/.seven`, `C:\Users\Bry\.seven`, sessions, chats, notes, profiles or personal files.
- **Work only inside the repository** (`o:\GitHub\seven`), using code inspection, mocks and static analysis.

## Before Any Change
Read [docs/seven_readme.md](docs/seven_readme.md). It holds every rule for working on Seven, and links to the procedure for recurring jobs such as making a plan.
